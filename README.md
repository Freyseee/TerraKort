# TerraKort
This is a free tool for generating and drawing maps! The tool can be run offline and is easily expandable by adding plugins :)

## How to open TerraKort
Inside each release is a Zip folder. Each release describes how to run it and any release-specific information

## TerraKort features
This section will expand as I add more features! The features listed will be the ones present in the current newest release

### Generating a map
When generating a map, any edits made with brushes, etc. are not saved. 


>**Seed**
>
>The seed is what makes each map unique! If there is a particular seed you like you can write it there anytime to generate it again.

---
>**Generate**
>
>The generate button generates a map from the chosen seed. 

---
>**Random**
>
>This button chooses a random seed and then generates the map correlating to the randomly generated seed.

---


### Brushes
Some brushes are included in the version I've made, but in the future I will make a very easy method for creating your own cool brushes!


>**Brush Sliders**
>
>>Brush: The size of the brush
>
>>Speed: How aggressive the brush is. The further to the right, the faster the map is changed by the brush.

---
>**Flatten**
>
>Using this brush, you click and hold on a surface and then drag along it to anywhere you want to be the same height

---

>**Sculpt**
>
>>Right click: Increase height. Can be used for making landmasses and mountains!
>
>>Left click: Decrease height. Can be used to remove mountains or turn landmasses into sea/beach

---

### Advanced Options
These options are shown in the panel of the right side of the screen. Click the **Apply** button to apply the settings :)

>**Map Size**
>
>>Fit to Window: 
>>Check to override the width and height to fit your screen :)
>
>>Width and Height: 
>>Can be used to manually choose the height and width of the maps area
>
>---

>**Noise**
>
>>Feature Size: 
>>How much the land area should be broken up. Left means many islands, right means minimal islands
>
>>Detail: 
>> To the left it results in very simple round shapes. To the right you add more detail meaning more complex shapes
>
>>Island Falloff: 
>>Determines how close to the edge the map will be generated. To the left it can generate on the whole area. To the right it just creates a landmass in the middle
